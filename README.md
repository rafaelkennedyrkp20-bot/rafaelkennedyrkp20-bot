## Projeto em destaque: LiveToon

O LiveToon é uma plataforma de webtoons criada para unir arte original, histórias exclusivas e uma leitura confortável em qualquer tela.

- Catálogo completo com busca, filtros por gênero/artista e carregamento progressivo
- Leitor responsivo com histórico, favoritos, comentários e preferências de leitura
- Comunidade pública com postagens, curtidas e comentários
- Notificações persistentes para novos projetos e capítulos
- Cadastro, sessões seguras, termos, proteção contra spam e painel administrativo
- Upload e organização de capítulos com validação de imagens
